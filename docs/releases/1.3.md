# Crenel 1.3

- **A cleaner, calmer layout everywhere.** The notch, the desktop window and Settings now
  share one spacing system: lists have room to scan, related things sit together, and
  every screen lines up on the same edges.
- **Easier lists.** Task rows are taller, calendar and recording rows keep their time tile
  as one tidy column, and section labels show their count beside the name ("Today · 3").
- **Settings on one card per page.** Each setting reads as a title with a short line under
  it and its control on the right, without a box around every row.
- **Roomier task input.** The "Add a task" field is easier to type in.
