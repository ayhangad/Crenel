# Crenel 1.4.1

- **Dictation asks for the access it needs.** Without Accessibility, Crenel could only copy
  what you said and pointed to its own Settings. Now macOS asks right away, and the notch
  shows Allow, which opens the right permission for Accessibility, the microphone or Input
  Monitoring.
- **The speech model downloads before your first dictation.** On a new Mac the first tries
  no longer fail with "isn't installed" or "Downloading".
- **The download can't get stuck.** If macOS had no room left for another dictation
  language, the model never downloaded; Crenel now frees the languages it no longer uses.
