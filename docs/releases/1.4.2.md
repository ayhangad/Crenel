# Crenel 1.4.2

- **Turkish dictation on more Macs.** When one of macOS's speech engines can't handle the
  language, Crenel now tries the other one instead of stopping with "language isn't
  supported". If neither can, the notch names the language and points to Dictation settings.
- **Recording settings stop asking to check system audio.** Once system audio access is
  confirmed, Settings no longer shows "Needs checking" and "Call audio off" after every
  restart.
